O que é um QR Code de trollagem?

Um QR Code de trollagem é uma forma divertida de compartilhar uma imagem, GIF ou conteúdo com outra pessoa usando um código que pode ser escaneado pelo celular.

Em vez de simplesmente enviar uma imagem pelo WhatsApp, você pode criar um QR Code e compartilhar o código. A pessoa escaneia e acessa o conteúdo associado.

Esta ferramenta foi criada para facilitar esse processo. Você pode informar o endereço de uma imagem ou selecionar uma foto do seu dispositivo.

```
```

Como criar um QR Code de trollagem?

  1. Escolha entre usar um link de imagem ou enviar uma foto.
  2. Se estiver usando um link, cole o endereço da imagem.
  3. Se estiver usando uma foto, selecione uma imagem do seu dispositivo.
  4. Clique em Gerar QR Code.
  5. Depois que o código aparecer, clique em Baixar QR Code.
  6. Compartilhe a imagem do QR Code com seus amigos.

Como funciona o QR Code?

QR Code significa "Quick Response Code". Ele é um código bidimensional que pode armazenar diferentes tipos de informações.

Quando uma câmera ou aplicativo compatível identifica o código, o celular interpreta os dados armazenados nele.

No caso desta ferramenta, o código pode conter um endereço de imagem ou os dados comprimidos de uma foto.

Perguntas frequentes

É grátis?

Sim. O gerador pode ser utilizado gratuitamente.

Preciso instalar algum aplicativo?

Não. A criação do QR Code acontece diretamente no navegador.

A foto é enviada para algum servidor?

Na opção de envio de foto, o processamento da imagem acontece no próprio navegador antes da criação do QR Code.

Por que algumas fotos não funcionam?

Um QR Code possui uma capacidade limitada de armazenamento. Fotos muito grandes ou detalhadas podem ultrapassar essa capacidade mesmo depois da compressão.

Posso baixar o QR Code?

Sim. Depois de gerar o código, utilize o botão "Baixar QR Code" para salvar a imagem.
